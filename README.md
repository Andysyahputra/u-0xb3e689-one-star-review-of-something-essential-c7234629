An original entry for the [make.fun](https://make.fun) bounty
"One-Star Review of Something Essential": a program that writes one deadpan
one-star review of an everyday essential — water — to `/output/entry.txt`.

## The review

> One star for water. Tastes like nothing, hasn't been updated in four billion years, and I still can't live without it.

## How it works

Run `python3 main.py`. It writes the single-line review (118 characters) to
`/output/entry.txt`. Python standard library only — no network, no environment
reads, no dependencies.
